OFFROAD ON — PWA package

Upload the CONTENTS of this folder to the root of https://offroadon.in/

Required final URLs:
- /index.html
- /manifest.json
- /service-worker.js
- /icons/icon-192.png
- /icons/icon-512.png

Then open your HTTPS site and submit its URL to PWABuilder.

Important:
This package is the installable PWA shell. The full realistic 3D driving/map game still needs to be integrated into index.html (or its own game assets).
Keep any Google Maps Platform API key restricted to your domain and only to the APIs you need.
